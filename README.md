# 바탕화면 부수기 (Desktop Destroyer) — 1단계

지금 쓰고 있는 바탕화면을 스크린샷으로 찍어 전체화면에 깔고, 마우스로 클릭해서 유리처럼 부수는 장난감이에요.

- 1단계 구현: 스크린샷 전체화면 + 안전장치(ESC / 60초 자동 종료) + 망치(유리 금)
- 2단계 예정: 총 / 화염방사기 / 폭탄
- 3단계 예정: 유리 조각이 우수수 떨어지며 진짜 바탕화면이 드러나는 엔딩

## 준비물 (Windows)

1. **Node.js** (LTS)
2. **Rust 1.90 이상** — 전역 단축키 플러그인 때문에 필요해요. `rustc --version`으로 확인하고, 낮으면 `rustup update`
3. **Visual Studio Build Tools** (C++ 데스크톱 개발) 와 **WebView2** — CursorToy 만들 때 이미 설치했으면 OK

## 설치

압축을 풀고 폴더에서:

```
npm install
```

## 실행 방법 (직접 실행해 주세요)

```
npm run tauri dev
```

- **처음 실행은 Rust 컴파일 때문에 오래 걸려요 (몇 분 ~ 10분 이상).** 두 번째부터는 빨라요.
- 앱이 시작되면 터미널에 `5초 뒤 화면을 캡처합니다` 라고 카운트다운이 나와요.
  그 5초 안에 **Win + D** 로 바탕화면을 보이게 하세요. (VSCode 창이 그대로 찍히면 안 되니까요)
- 5초 뒤 화면이 캡처되고, 바탕화면과 똑같은 모습으로 전체화면이 덮여요. 이제 클릭하면 부서져요!

## 조작키

| 키 | 동작 |
| --- | --- |
| 마우스 왼쪽 클릭 | 망치로 때리기 |
| `ESC` | 즉시 종료 (창이 포커스를 잃어도 동작하는 전역 ESC도 있어요) |
| `H` | HUD 숨기기/보이기 (촬영할 때는 숨기세요) |
| `R` | 부서진 것 전부 되돌리기 (촬영 재시도용) |
| `M` | 소리 끄기/켜기 |
| `1` | 망치 선택 (2~4는 아직 잠겨 있어요) |

## 안전장치 (중요)

전체화면 오버레이라서 안전장치를 여러 겹으로 넣어놨어요.

1. `ESC` 키 → 바로 종료 (전역 단축키라서 웹뷰가 멈춰도 동작)
2. **60초 자동 종료** — 오버레이가 뜬 뒤 60초가 지나면 무조건 꺼져요. (화면 위쪽에 `AUTO-EXIT` 카운트다운이 보여요)
3. 앱이 준비되기 전에는 창을 아예 띄우지 않아요. 중간에 문제가 생기면 창이 뜨지 않은 채 스스로 종료해요.
4. 최악의 경우: 작업 관리자(Ctrl+Shift+Esc)에서 `desktop-destroyer` 프로세스를 끝내면 돼요.

시간을 바꾸고 싶으면 `src-tauri/src/lib.rs` 맨 위의 상수를 수정하세요.

```rust
const CAPTURE_DELAY_SECS: u64 = 5;   // 시작 후 캡처까지 대기 시간
const MAX_RUN_SECS: u64 = 60;        // 오버레이 최대 실행 시간
```

## 처음 실행했을 때 확인할 것

1. `npm run tauri dev` 후 터미널에 카운트다운이 나오나요?
2. 5초 뒤 **바탕화면과 똑같은 화면**이 전체화면으로 뜨나요? (작업표시줄까지 덮이는지도 봐주세요)
3. 클릭하면 망치가 내려치고 유리 금이 쫙 퍼지나요? 소리가 나나요?
4. 여러 번 클릭하면 점점 가장자리가 어두워지나요?
5. `H`, `R`, `M` 키가 동작하나요?
6. `ESC` 로 바로 꺼지나요?

문제가 있으면 **어떤 단계에서 어떤 현상이 나왔는지**(터미널 에러 메시지 포함)를 알려주세요.
